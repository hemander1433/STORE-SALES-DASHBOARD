Project Overview

This project presents an interactive Store Sales Analysis Dashboard built using Power BI Desktop.
The objective was to analyze retail sales data to uncover trends in sales, profit, customer segments, shipping modes, and regional performance, along with implementing a basic forecasting model for future sales.

Objective

Transform raw sales data into meaningful business insights

Track key performance indicators (Sales, Profit, Quantity, Returns)

Identify high-performing categories and sub-categories

Analyze seasonal sales trends

Perform basic sales forecasting
